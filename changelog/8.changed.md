`qdac.play`'s `dwell` is now an integer number of microseconds, default `2`, and `qdac.play`'s `delay` and `qdac.set_trigger`'s `duration` are now seconds, as a `float`; no migration is registered, so a `.qp` file written with 0.2 loads with its numbers read in the new units. The `qdac-default-v1` profile, now at version 0.2.0, rejects a `dwell` under 2 microseconds with a `qdac.dwell-below-minimum` error, and no longer publishes the `min_dwell_ns: 100` limit, which no check read.
